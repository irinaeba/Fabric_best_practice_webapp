Key distinction

ABFS success proves storage-path authentication and OneLake reachability. It does not prove SQL driver support, SQL-audience token acquisition, TDS network routing, Fabric SQL item access, database selection, or SQL object authorization.

ABFS path: Entra token for https://storage.azure.com/.default, then OneLake DFS over HTTPS/TCP 443.
SQL path: Entra token for https://database.windows.net/.default, then Fabric SQL over MSSQL/TDS/TCP 1433.
Public static documentation. No credentials, access tokens, tenant IDs, endpoint IDs, or proof screenshots are published here.
