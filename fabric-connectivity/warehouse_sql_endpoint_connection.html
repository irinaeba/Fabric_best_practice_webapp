Fabric Warehouse SQL Endpoint

A standalone service-principal connectivity test for Microsoft Fabric Warehouse. It connects over encrypted TDS on port 1433, lists visible tables, and reads a configured table.

1. Installpip install pyodbc python-dotenv and Microsoft ODBC Driver 18.
2. ConfigureCreate .env from the template below. Never email the client secret.
3. Runpython test_warehouse_sql_endpoint.py
Required access: item-level Read on the Warehouse for connectivity, plus SQL SELECT on the required schema/table. Workspace Contributor already has broader SQL access and should not be used for least-privilege integrations.

Environment template

TENANT_ID=your-tenant-id
CLIENT_ID=your-service-principal-client-id
CLIENT_SECRET=provide-securely-do-not-email

# Copy from Fabric Warehouse > Settings > SQL endpoint.
WAREHOUSE_SQL_SERVER=<endpoint-id>.datawarehouse.fabric.microsoft.com
# Fabric Warehouse item name; this is the SQL database name.
WAREHOUSE_SQL_DATABASE=My_Warehouse_Name
WAREHOUSE_SQL_SCHEMA=dbo
WAREHOUSE_SQL_TABLE=my_table
