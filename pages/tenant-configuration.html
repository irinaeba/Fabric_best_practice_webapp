2. Tenant Configuration

UAE-specific tenant settings, features to disable for data sovereignty, and admin role delegation.

⚠ Critical: UAE Data Sovereignty

Abu Dhabi government entities are not permitted to process data outside the UAE. Several Fabric features route data through Azure OpenAI or third-party services that may process data outside your capacity's geographic region. These must be disabled at the tenant level before any data is loaded.

Standard Fabric workloads are NOT affected — Lakehouse, Warehouse, Notebooks, Data Factory pipelines, Semantic Models, OneLake, and Power BI reports all process data within your capacity's region.

Admin Roles & Delegation

Fabric supports multiple admin levels to distribute responsibility. Do not concentrate all admin rights on a single person.

Role Scope Responsibilities Typical Government Persona
Fabric Administrator Entire tenant Tenant settings, feature toggles, capacity management, audit logs, user management IT Director / Head of Digital Infrastructure / Platform Team Lead
Capacity Administrator Specific capacity (F-SKU) Manage capacity settings, assign workspaces to capacity, monitor consumption, scale Platform Engineer / Cloud Operations Lead
Domain Administrator Business domain (e.g., Tourism, Culture) Override delegated tenant settings for the domain, manage domain-level governance Department Data Lead / Chief Data Officer (department-level)
Workspace Administrator Individual workspace Manage workspace access, assign roles, configure Spark environments, connect to Git Project Lead / Senior Data Engineer / Analytics Team Lead

Delegation Best Practices

  • Fabric Admin sets organisation-wide policies (features to disable, security baseline)
  • Capacity Admin is delegated to the team managing Azure subscriptions and billing
  • Domain Admins are closer to the business — they understand data sensitivity within their department
  • Workspace Admins are the team leads who manage day-to-day access for their project members
⚡ Principle of Least Privilege
Not every IT staff member needs Fabric Admin rights. Delegate capacity and workspace admin roles to the appropriate team leads. Reserve Fabric Admin for the central platform team (1–3 people maximum).

Additional Tenant Settings to Review

Beyond the sovereignty-critical features above, review these settings for a government environment:

Setting Recommendation Reason
Publish to web DISABLE Prevents public exposure of government data
External sharing (B2B guest access) DISABLE or restrict to approved domains Control data leakage outside the organisation
Export to Excel / CSV / PDF REVIEW May need to be restricted based on data classification
Self-service workspace creation DISABLE for general users Prevent workspace sprawl; require approval process
Self-service capacity trials DISABLE Centralise capacity provisioning
Allow service principals to use Fabric APIs ENABLE for specific security groups Required for CI/CD automation

Where to Configure

All tenant settings are managed in the Fabric Admin Portal:

  1. Sign in to app.fabric.microsoft.com
  2. Click the Settings gear icon → Admin portal
  3. Navigate to Tenant settings
  4. Search for each setting listed above and configure accordingly
